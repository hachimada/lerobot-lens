# Offline demo dataset

This directory contains only the bundled `hachimada/so101_pick_place_red_1` Episode 0 data used by offline demo mode:

- `episode_000.npz`: observations, actions, and timestamps
- `frames/`: front-camera JPEG frames
- `metadata.json`: episode metadata and feature names
- `DATASET_CARD.md`: source dataset information

Robot URDFs, meshes, and robot licenses are managed separately under `../robots/`.
